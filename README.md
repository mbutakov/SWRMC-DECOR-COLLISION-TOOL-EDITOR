# SWRMC — Decor Editor

Редактор декораций для Minecraft: загрузка Blockbench-моделей, предпросмотр, настройка OBB-коллизий и экспорт готового пакета.

## Возможности

- точные, кластерные и упрощённые OBB-коллизии;
- выбор и перемещение боксов, ручная правка и `Ctrl/Cmd+Z`;
- одиночные и мультитекстурные модели с atlas;
- импорт моделей с `parent` из resource pack;
- безопасный экспорт `model.json`, `collision.json`, `meta.json` и PNG.

## Запуск

```bash
cargo run --release
```

Перетащите JSON-модель и связанные PNG в окно редактора, настройте коллизии и выберите папку для экспорта.

## Релиз

В GitHub Actions запустите workflow **Build SWRMC** вручную и укажите тег версии. Сборки Windows, macOS и Linux появятся в созданном релизе.
